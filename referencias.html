Tags Básicas

<h1> ao <h6>: Definem a hierarquia de títulos no documento.

<p>: Define um parágrafo de texto.

<br>: Insere uma quebra de linha.

<hr>: Representa uma divisão temática no conteúdo.

<strong>: Indica que um texto possui grande importância.

Links e Imagens

<a href="...">: Tag âncora utilizada para criar hiperlinks absolutos, relativos ou de fragmento.

<img src="..." alt="...">: Utilizada para exibir imagens na página.

target="_blank": Permite abrir um link em uma nova aba do navegador.

href="#id": Permite navegar diretamente para uma seção da página identificada pelo atributo id.
