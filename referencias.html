Tags Básicas

<h1> até <h6>: definem a hierarquia dos títulos de uma página.

<p>: define um parágrafo.

<br>: insere uma quebra de linha.

<hr>: cria uma divisão temática no conteúdo.

<strong>: indica que um texto possui importância.

<em>: dá ênfase a um trecho do texto.

Listas

<ul>: cria uma lista não ordenada, com marcadores.

<ol>: cria uma lista ordenada, com números.

<li>: representa um item de uma lista.

As listas podem ser aninhadas, permitindo criar sublistas dentro de outros itens.

↑ Voltar ao topo





Links e Imagens

<a href="...">: cria um hiperlink para outra página ou endereço.

<img src="...">: permite inserir uma imagem na página.

O atributo alt fornece um texto alternativo para a imagem.

O atributo target="_blank" permite abrir um link em uma nova aba.

Tabelas

<table>: cria uma tabela.

<tr>: representa uma linha da tabela.

<th>: representa uma célula de cabeçalho.

<td>: representa uma célula de dados.

↑ Voltar ao topo





Formulários

<form>: define um formulário para entrada de dados.

<input>: permite a inserção de informações pelo usuário.

<label>: identifica um campo do formulário.

<button>: cria um botão interativo.
